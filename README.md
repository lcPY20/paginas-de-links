# Luca Dev - Página de Links

Este projeto é uma página de aterrissagem pessoal (landing page) simples e elegante, projetada para agregar links importantes e apresentar um perfil de usuário. É ideal para uso em biografias de redes sociais.

## 🚀 Tecnologias Utilizadas

O projeto foi desenvolvido utilizando as tecnologias fundamentais da web:

*   **HTML5** (`index.html`): Estrutura semântica da página.
*   **CSS3** (`style.css`): Estilização moderna com variáveis (`:root`), Flexbox, gradientes e animações de hover.
*   **JavaScript** (`script.js`): Funcionalidades interativas simples.

## 📂 Estrutura do Projeto

*   **`index.html`**: O arquivo principal que contém os elementos da página, como a imagem de perfil (`.perfil`), os botões de link (`.link`) e o botão de compartilhamento.
*   **`style.css`**: Define a identidade visual, incluindo:
    *   Fundo com gradiente linear (`#667eea` para `#764ba2`).
    *   Botões responsivos com efeitos de sombra e transição.
    *   Fonte 'Inter' para uma tipografia limpa.
*   **`script.js`**: Contém a lógica de scripts, incluindo a função `dizerOla()` que exibe uma mensagem de boas-vindas ao usuário.

## 🔧 Como Executar

1.  Clone este repositório ou baixe os arquivos.
2.  Certifique-se de que `index.html`, `style.css` e `script.js` estejam na mesma pasta.
3.  Abra o arquivo `index.html` em qualquer navegador moderno (Chrome, Firefox, Edge, etc.).

## 🎨 Personalização

Você pode alterar facilmente as cores principais editando as variáveis no topo do arquivo `style.css`:

```css
:root {
    --primary-color: #764ba2; /* Cor do texto dos botões */
    --hover-color: #f0f0f0;   /* Cor de fundo ao passar o mouse */
}
```
